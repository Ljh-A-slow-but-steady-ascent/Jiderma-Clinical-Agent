# 多样外观

美国皮肤科学会指出，基底细胞癌可表现为坚实隆起的圆形生长物、中央凹陷的区域、鳞屑性斑片、反复愈合又破溃的伤口、瘢痕样新生斑或闪亮丘疹。颜色可为粉红、红、褐、黑、蓝灰或接近肤色，不能因颜色或生长缓慢而排除。

# 风险边界

基底细胞癌通常生长较慢且很少远处扩散，但可向深部组织生长并破坏局部结构。头面部、鼻、眼睑、耳周等重要解剖部位，或病灶持续增大、出血、结痂和反复破溃时，延误评估可增加局部损害。

# 确认方式

是否为基底细胞癌需由皮肤科医生评估，必要时通过活检和组织病理确认；不应仅凭单张图像宣告癌症诊断。
