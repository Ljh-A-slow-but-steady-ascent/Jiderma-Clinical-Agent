# 疾病范围

“良性角化性病变”可涵盖脂溢性角化病、日光性黑子，以及可由前两者发生炎症和退行而形成的扁平苔藓样角化病，并不指向单一疾病。

# 常见特征

DermNet 资料描述，脂溢性角化病常为界限清楚、像“贴上去”的蜡样或疏状斑块，颜色可从黄褐到黑色；日光性黑子多为日晒部位的扁平色素斑。这些外观特征并非特异，炎症、摩擦或退行可使病灶外观改变。

# 不能仅看图确认

色素较深、结构不对称或发生变化的良性角化性病变，可与基底细胞癌、鳞状细胞癌或黑色素瘤相似。若临床和皮肤镜仍不能区分，需由医生决定是否进行活检或诊断性切除。
