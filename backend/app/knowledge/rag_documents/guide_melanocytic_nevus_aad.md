# 一般认识

黑素细胞痣很常见，大多数普通色素痣不需要治疗。对单个病灶的评估应关注它与本人其他痣是否相似、是否长期稳定，以及病程中是否出现新的变化。单张皮肤镜图片通常不包含这些纵向信息。

# 应就医复核的变化

美国皮肤科学会建议，成年人新出现的痣，或原有斑点持续增大、瘩痒、出血，以及颜色、形状、边界发生变化时，应安排皮肤科医生检查。不能因为外观似良性就忽略变化、出血等警示信号。

# 与黑色素瘤的边界

色素痣和早期黑色素瘤可有外观重叠。对可疑病灶，医生会结合全身对比、皮肤镜、动态随访和必要时的病理检查判断；仅凭单张图像不具有这种确诊能力。
