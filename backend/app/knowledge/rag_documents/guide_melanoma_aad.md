# ABCDE 警示

美国皮肤科学会提供的 ABCDE 警示包括：A 不对称；B 边界不规则、呈锯齿或模糊；C 同一病灶内颜色不均；D 直径常大于6毫米但也可更小；E 大小、形状或颜色持续变化。“与其他痣明显不同”的丑小鸭表现也需重视。

# 高风险变化

新出现的异常色素斑，或原有病灶快速增大、变色、变形、瘩痒、出血和破溃，应由皮肤科优先评估。黑色素瘤可以发生在日晒或非日晒部位，也可出现于指趾甲周围或足底等位置。

# 确诊边界

ABCDE 是就医警示而非确诊规则。仅凭单张图像不能确诊或排除黑色素瘤；确认需结合医生检查、皮肤镜及必要时的组织病理。
